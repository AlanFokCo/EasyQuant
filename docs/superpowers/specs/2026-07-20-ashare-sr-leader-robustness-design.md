# A 股行业龙头支撑压力策略稳健化设计

## 状态

- 日期：2026-07-20
- 状态：设计已确认，等待书面规格审阅
- 基线策略：`adaptive_composite`
- 基线区间：2020-01-01 至 2025-12-31
- 基线结果：评级 A / 71.3，年化收益 16.54%，最大回撤 -24.28%，Sharpe 0.77

## 背景

当前 `adaptive_composite` 已把全周期评级从 B 提升到 A，但稳健性仍有三个明显短板：

1. `risk_adjusted` 维度仅为 38.5，主要受 Sharpe 和 Calmar 偏低影响。
2. 最大回撤为 -24.28%，高于希望控制在 20% 内的目标。
3. 2025 分段评级为 D，没有完成交易，并相对基准落后 14.15%。

下一轮研究不再以单纯提高全周期评级为第一目标，而是优先降低回撤、改善失效阶段并验证参数邻域稳定性。允许年化收益从 16.54% 回落，但目标下限为 12%。

## 目标

本设计的目标是形成一个可选的稳健版行业龙头策略，并满足以下验收条件：

- 全周期年化收益不低于 12%。
- 全周期最大回撤严格小于 20%。
- 全周期评级保持 A，即评分不低于 70。
- 2025 压力验证期相对基准落后不超过 5%。
- 任一滚动验证期相对基准落后不超过 10%。
- 相邻参数组合中至少 60% 保持年化收益不低于 10%、最大回撤不超过 22%。

这些条件是研究门槛，不是对未来实盘表现的承诺。

## 非目标

- 不修改通用回测引擎的撮合、成本或评分公式。
- 不扩大到全市场动态股票池，也不改变现有行业龙头池的构造方式。
- 不使用日内数据、高频信号、机器学习模型或大规模随机参数寻优。
- 不为了得到更高评级而改变 `grade_strategy` 的评分标准。
- 不保证本轮一定产生可替换当前基线的候选策略。

## 方案选择

研究阶段比较过三条路线：

1. 仅调整仓位、止损和现有过滤参数。改动最小，但难以修复 2025 年主信号不足的问题。
2. 只增加组合风险预算。更容易降低回撤，但仍可能长期空仓。
3. 双通道选股叠加组合风险预算。保留原策略收益来源，在主信号稀少时允许严格受限的候补持仓，并用风险状态机控制总风险。

最终选择第三条路线。原 `adaptive_composite` 保留为基线，新功能通过参数显式启用，关闭时保持原行为。

## 总体架构

稳健版策略由四个边界清晰的组件构成：

1. **主信号选择器**：复用现有突破、回踩、支撑距离、相对强弱和成交量逻辑。
2. **候补信号选择器**：仅在主信号数量不足时，从趋势未破坏、相对强势且低波动的龙头中补充有限仓位。
3. **组合风险预算器**：把大盘状态仓位、市场波动系数和组合回撤系数相乘，得到最终权益风险预算。
4. **稳健研究选择器**：先执行硬门槛和滚动验证，再比较候选评分，禁止仅凭全周期最高评级选中策略。

月度调仓的数据流如下：

```text
已完成历史 K 线
    -> 大盘状态与市场波动率
    -> 主信号候选
    -> 主信号不足时生成候补候选
    -> 更新组合风险状态
    -> 计算最终风险预算
    -> 主通道优先、候补通道受限的波动率权重
    -> 单股/行业/流动性约束
    -> 调仓指令
```

周度复查负责更新组合回撤状态、执行结构破位和移动回撤退出，并在必要时把现有仓位压缩到新的风险预算内。

## 双通道选股

### 主信号通道

主通道保持当前 `adaptive_composite` 行为，包括：

- 支撑和压力位只使用当前时点之前已经完成的 K 线。
- 突破需要 ATR 缓冲、量比确认和正相对强弱。
- 回踩需要未破位、位于支撑上方并处于允许的支撑距离内。
- 候选按回踩、突破、支撑距离、相对强弱、波动率和量比综合打分。

主通道始终优先使用风险预算。候补通道不能替换或挤占已经通过主信号的持仓。

### 候补信号通道

只有主信号候选少于 `min_primary_candidates` 时才启用候补通道。建议初始研究值为 5，并在有限邻域内比较 4、5、6。

候补股票必须同时满足：

- 没有触发结构破位。
- 收盘价位于 120 日均线上方。
- 60 日均线相对 20 个交易日前没有下降。
- 60 日相对基准强弱不低于 0。
- 20 日波动率不高于当期合格股票的中位数。
- 平均成交量、最低价格和板块排除规则与主通道一致。

候补评分只包含趋势斜率、相对强弱和低波动奖励，不复用突破或回踩奖励。候补候选只填补主信号留下的空位，组合总候补仓位初始上限为 25%。弱势市场和组合防守、保护状态下禁用候补买入。

策略需要记录每个持仓的入场通道。主通道持仓继续使用结构破位退出；候补持仓额外使用 8% 至 10% 的近期高点移动回撤退出。研究默认从 10% 开始，避免过度止损造成换手上升。

## 组合风险预算

最终权益预算定义为：

```text
最终权益预算 = 大盘状态仓位 × 市场波动系数 × 组合回撤系数
```

三个系数都限制在 0 到 1 之间。最终结果仍受现金、单股、行业和流动性限制。

### 大盘状态仓位

继续使用现有 `strong`、`neutral`、`weak` 三态分类和对应仓位参数，不改变原始市场结构判断。

### 市场波动系数

使用基准最近 20 个交易日收益率计算年化波动率，并按下式缩放：

```text
市场波动系数 = clamp(目标年化波动率 / 实际年化波动率, 0.55, 1.00)
```

目标年化波动率初始值为 18%，有限比较 16%、18%、20%。实际波动率低于目标时不加杠杆，实际波动率升高时逐步降仓。

### 组合回撤状态机

组合净值高水位、阶段低点和当前风险状态保存在策略运行状态中。风险状态转换如下：

| 状态 | 触发条件 | 回撤系数 | 候补买入 |
|---|---:|---:|---|
| `normal` | 回撤 < 8% | 1.00 | 允许 |
| `cautious` | 回撤 >= 8% | 0.75 | 允许，但受候补上限约束 |
| `defensive` | 回撤 >= 12% | 0.50 | 禁止 |
| `protect` | 回撤 >= 16% | 0.25 | 禁止，只允许减仓和退出，不得新开仓 |

降级立即生效。升级必须同时满足：

- 组合已从本轮阶段低点收复至少一半高水位到低点的损失。
- 大盘状态不是 `weak`。
- 基准和组合状态数据完整。

每次周度复查最多恢复一个等级，防止一次性重新加满仓。风险状态升级后仍需等待下一次正常调仓才允许新增仓位。

### 权重分配

通过门槛的候选使用逆波动率形成初始权重，再按以下顺序裁剪：

1. 主通道分配优先。
2. 候补通道总权重不超过候补仓位上限。
3. 单股权重不超过 `max_stock_weight`。
4. 单行业权重不超过 `max_industry_weight`。
5. 增仓继续受成交量流动性上限约束。

裁剪后不强制把剩余现金重新分配，避免行业上限或候补上限被间接突破。

## 缺失数据和异常处理

- 基准行情缺失或不足时，不得提高风险状态、增加目标仓位或启用候补通道。
- 个股数据不足时跳过该股票，不用零值或跨标的数据代替。
- 风险数据缺失时沿用更保守的现有风险等级，只允许风险降低型订单。
- 新上市股票在请求区间无历史数据时继续使用现有本地缓存短路逻辑，不回退到隐式网络请求。
- 没有候选策略通过研究硬门槛时，报告明确说明本轮未找到更稳健版本，并保留当前 A / 71.3 基线。

## 研究与选择规则

### 参数空间

参数搜索保持有限且可解释，只覆盖：

- 主信号不足阈值：4、5、6。
- 候补总仓位上限：20%、25%、30%。
- 候补移动回撤：8%、10%。
- 目标年化波动率：16%、18%、20%。
- 风险状态回撤阈值的少量保守邻域。

不同时大范围搜索原策略全部参数。第一轮固定当前 A 级基线的主信号参数，只研究新增稳健组件；只有新增组件表现稳定后，才允许对主信号参数做局部邻域验证。

### 滚动验证

同一组固定参数依次在以下窗口评估：

- 2020-2022 作为形成期，2023 作为验证期。
- 2021-2023 作为形成期，2024 作为验证期。
- 2022-2024 作为形成期，2025 作为压力验证期。

形成期只用于预热指标和组合风险状态，不在窗口内重新选择参数。验证指标只统计随后一个验证年度。这些窗口用于观察同一组固定参数在不同市场阶段的表现。由于 2025 的问题已经用于制定本设计，报告必须称其为压力验证期，不能称为完全未见样本。

### 硬门槛与排序

候选先执行本设计“目标”章节中的全部硬门槛。通过后按以下顺序排序：

1. 参数邻域通过率。
2. 最差验证期超额收益。
3. 全周期 Sharpe。
4. 最大回撤绝对值，越小越好。
5. 月度胜率。
6. 全周期年化收益。

全周期评级只作为硬门槛，不再作为通过门槛后的第一排序条件。

## 报告变更

研究报告在保留当前基线排名的同时新增：

- 每个候选的硬门槛通过或失败原因。
- 三个滚动验证期的收益、超额收益、回撤和评级。
- 参数邻域通过率和最差验证期表现。
- 各风险状态持续时间、触发次数和恢复次数。
- 主通道与候补通道的持仓数量、成交次数、平均风险暴露和收益贡献。
- 当前基线与稳健候选的并列比较。

收益贡献使用前一交易日通道持仓权重乘以下一交易日个股收益进行日频归因，再按通道累加。该归因用于比较两类信号，不修改回测引擎的总收益计算。

## 测试策略

### 单元测试

- 候补信号必须满足趋势、相对强弱、波动率和未破位条件。
- 主信号充足时不得启用候补通道。
- 主通道候选优先于候补候选，候补总权重不能突破上限。
- 逆波动率权重仍满足单股和行业约束。
- 波动率系数在 0.55 到 1.00 之间，且不产生杠杆。
- 回撤达到 8%、12%、16% 时进入正确风险状态。
- 降级立即生效，恢复每周最多一级，并要求损失收复和非弱市条件。
- 候补持仓使用更严格的移动回撤退出。
- 缺失基准或风险数据时只能维持或降低风险。
- 关闭稳健功能时，当前 `adaptive_composite` 行为保持不变。

### 集成与回归测试

- 研究脚本能同时运行当前基线和稳健候选，并生成确定性排序。
- 硬门槛失败的候选不会被选为最终策略。
- 没有候选通过时仍成功生成报告，并明确保留基线。
- 所有信号只读取回调时点之前的历史数据。
- 交易成本继续使用印花税 0.05%、佣金 0.025%、最低 5 元。
- 重新生成 2020-2025 HTML、Markdown、CSV 和 JSON 报告。
- 更新中英文策略说明，并通过 `python scripts/check_doc_sync.py`。
- 运行相关策略测试、完整测试套件、示例烟雾测试和文档构建。

## 完成标准

实现只有在以下条件全部满足时才算完成：

1. 双通道选择、风险预算和恢复状态机均有确定性测试。
2. 当前基线在关闭新功能时没有行为回归。
3. 完整研究运行结束且报告可复现。
4. 至少一个候选通过全部硬门槛；或者报告明确、诚实地说明没有候选通过并保留当前基线。
5. 中英文文档同步，相关测试和仓库要求的校验命令通过；无法通过的现有告警必须在交付说明中列出。
