数据来源
指标计算说明
行情数据
AKShare — 东方财富接口
A股日线 OHLCV 行情通过 stock_zh_a_hist 获取，前复权（qfq）处理。前复权已将历史分红纳入价格调整，回测收益已反映分红影响。数据由东方财富网提供，仅供研究使用。
基准指数
沪深300（000300）· 上证综指（000001）
通过 AKShare stock_zh_index_daily_em 获取，以回测起始日收盘价归一化后与策略区间对齐。
无风险利率
固定 3.0% / 年
参考近年中国国债市场平均利率水平，用于 Sharpe、Sortino、Alpha 等超额收益指标的计算（日化 = 3% ÷ 252）。
回测引擎
EasyQuant — eqlib
基于事件驱动框架，以每日收盘价成交（T+1 制度），含双边手续费与最小交易单位（100股）限制。
  • 年化收益率(1 + 总收益率)^(252/N) − 1，N 为回测交易日数，每年按 252 个交易日折算。
  • Sharpe 比率(日均收益率 − r_f/252) / 日收益率标准差 × √252。参考：Sharpe (1966, 1994)。
  • Sortino 比率同 Sharpe 但分母仅用下行波动率（仅负收益标准差）。参考：Sortino & Price (1994)。
  • 最大回撤max[(峰值 − 谷值) / 峰值]，反映策略可能面临的最大历史亏损幅度。
  • Calmar 比率年化收益率 / |最大回撤|，衡量单位回撤的年化回报。参考：Young (1991)。
  • Alpha / Beta基于 CAPM，以沪深300为市场基准。β = Cov(R_p,R_m)/Var(R_m)；α = R_p − [r_f + β(R_m − r_f)]（均年化）。参考：Sharpe (1964)，Lintner (1965)。
  • 胜率按先进先出（FIFO）配对买卖，盈利对数 / 全部配对数。注意需结合盈亏比综合评估。
  • ATR(14)14日平均真实波幅，反映近期价格波动区间均值。参考：Wilder (1978)。
  • 支撑/压力位20日滚动最低/最高价计算，动态非静态水平线。
  • 量比当日成交量 / 近20日成交量均值，>2 通常视为明显放量信号。
